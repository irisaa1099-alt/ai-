# 趣聊：角色私聊、多人群聊与狼人杀

这是 R3 中性参赛分发，包含六名虚构角色、MIT自有代码及第三方许可，不含正式人物库、私人聊天、设置或密钥。

在 `app` 目录运行 `node server.mjs --no-open`，打开 http://127.0.0.1:5180 并配置自己的模型服务。添加至少五名角色，建群后可开六人狼人杀。

明确改期可停用同会话的旧安排；一次纠正关联同一角色的同义事实，保留独立时间等信息。重新整理及刷新后，私聊和群聊均已真实核对。旧“不知道”回复不再作为当前事实压过新确认。

正式31×3×2共186条真实回答；AI语义复核及Codex校对后，当前60/62、独立角色摘要58/62、仅窗口11/62。新增13类专项当前26/26。整体仍有撤回后无依据推断，单模型两次重复不证明普遍优越性。历史六组240条保留全组审核。未开展用户试用或独立人工评审。

同义关联依赖模型，仅覆盖当前角色有效事实和最近80条可见消息，需可用模型服务并产生额外调用；不会跨角色广播纠正。开发失败、原始回答、裁判原判与显式恢复记录随完整包提供。
