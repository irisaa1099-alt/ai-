# 趣聊 AIC 2026 参赛版本

让多角色按实际经历使用记忆，并支持查看来源、纠正和撤回。

本分支为固定的中性模板参赛副本，不含原人物模板、用户聊天、密钥或模型权重。核心实现来自主分支提交 c6deb4555ffcc165eb6c4c99677ac8ff5d11cf83，文件校验见 RELEASE_MANIFEST.json。

## 启动

安装 Node.js 22 或更新版本，进入 app 目录执行 `node server.mjs --no-open`，打开 http://127.0.0.1:5180，并在设置里配置自己的模型。
