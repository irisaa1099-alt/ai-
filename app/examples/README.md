# 最小记忆流程示例

在 app 目录运行 `node examples/memory-flow.mjs`。无需浏览器、数据库、依赖安装或 API Key。

示例直接调用产品的 core/memory.js、core/recent.js 和 core/util.js，依次展示：按听众筛选 → 校验提取来源 → 人工纠正 → 阻止旧原文再次注入 → 撤回。8条断言覆盖新成员不可见、拒绝伪造来源与纠正后历史保留等行为。

移植到自己的项目时复制上述三个模块，并实现消息存储适配：

1. 从自己的存储读取消息，检查消息归属与发送时听众。
2. 用 makeMemorySource 创建来源映射，再把实际提取结果交给 mergeExtractedMemory。
3. 保存整个记忆对象，不能只保存 active 文本，否则会丢失纠正历史与来源阻止记录。
4. 每次装配前验证原消息存在、内容签名未变；本示例没有实现持久层校验。产品里的 getMemory 承担这一部分。
5. 对当前历史、跨会话经历和引用应用 filterMemoryContext，再用 selectMemoryFacts 按预算选事实。

示例中的提取结果是明确标注的合成夹具，不调用模型、不证明模型提取质量。内容签名不用于身份认证。该模块提供听众与来源约束，不提供端到端加密，也不等于逐事实公开授权。
