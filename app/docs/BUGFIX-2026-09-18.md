# 2026-09-18 缺陷修复记录

本次修复针对一次全模块只读审查发现的数据同步、代理、生成中断问题。测试使用独立临时数据库，不使用真实 `data/db` 或真实模型密钥。

## 数据与同步

- 启动回填改为先完整读取每个角色的消息、记忆和每个群的消息；任一请求失败或消息格式无效时中止本次回填，保留浏览器现有数据库并报告同步错误，不再将读取失败当作空聊天记录。
- `/api/db/replace` 的“防误删检查 → 安全快照 → 清目录 → 重写”现在处于同一全局文件锁内。整库清空、实体删除和单会话记录重写也与普通镜像写入串行，避免并发写入跨过清空边界；单会话重写统一按“全局锁 → 文件锁”取锁，防止死锁。
- 运行时状态增加 `updatedAt`。启动回填时对每个角色/群选择更新时间较新的整条状态，允许好感度真实下降；旧版双方都没有时间戳时遵守磁盘优先。磁盘状态为空时仍可保留本地较新状态。导入的运行时状态与恢复默认设置现在也会镜像写盘。

## 模型代理与语音

- `/api/llm` 不再重复检查请求体里的代理口令，统一使用 `/api/*` 的来源与远程口令守卫：本机免口令，局域网可通过登录 Cookie 或 `X-Aichat-Token` 请求头授权。浏览器手填的口令改由请求头发送。
- Ollama、LM Studio 按供应商 ID 判断为无密钥本地服务；在代理模式下不再误要求 API Key。
- 新增 `/api/models`：代理模式的“获取模型列表”由服务端携带对应供应商密钥请求上游，浏览器不再无密钥直连。自定义上游地址仍受 `AICHAT_ALLOWED_UPSTREAMS` 限制。
- LLM 与 TTS 代理只发送用户明确填写的上游覆盖地址。未填写时由服务端选官方默认地址，因此白名单只约束自定义覆盖地址，不会误拦默认供应商。

## 私聊与群聊中断

- 私聊生成以当前任务身份管理忙状态；旧请求停止后，其迟到的 `finally` 不会解除新请求的忙状态。若停止发生在读取记忆期间，不再继续发出已取消的模型请求；消息落库期间停止也不再重复保存同一段回复。
- 群聊轮次也按任务身份保护全局状态和界面回调。已停止的旧轮次不会覆盖新轮次的忙状态、气泡或消息列表；引擎在异步准备步骤后再次检查停止标志，避免停止后才发出请求。
- Service Worker 缓存版本更新为 `aichat-v40`，使已安装的页面能取得本次更新后的模块。
