# Windows x64 本地模型版

完整便携包包含应用源码、Qwen3 4B 模型权重、Ollama 0.40.13 和 Node.js 24.22.2。无需单独安装 Node.js 或 Ollama，也无需商业 API Key。只调用随包的本地模型。

## 使用

1. 把 ZIP 完整解压到可写的本地文件夹，例如 `D:\Quliao`。不要直接在压缩包内运行，也不要放进需要管理员写权限的 Program Files。
2. 双击 `启动趣聊-Windows.bat`，也可以运行同内容的 `Start-Windows.bat`。
3. 保持启动窗口打开。模型准备完成后会自动打开 `http://127.0.0.1:5180`。没有自动打开时，手动把这个地址粘贴到浏览器。
4. 「设置 → 模型 → 测试连接」会生成真实回复；通过后即可创建角色聊天。
5. 结束使用时回到启动窗口按 Ctrl+C。启动脚本会尝试停止本次创建的网站及模型进程树。

模型已随包提供，首次启动只建立本机配置，不需要重新下载权重。基础模型文件缺失时，启动脚本才尝试从官方仓库补齐。

## 运行条件

- 面向 Intel / AMD 的 Windows x64；不提供 Windows ARM64 原生包。
- Ollama 官方要求 Windows 10 22H2 或更新版本；建议使用 Windows 11。
- 建议 16GB 内存；请为压缩包与解压文件共预留至少 15GB 可用空间。
- GPU 加速取决于显卡与驱动；CPU 推理可用性和速度需要在实际电脑上确认。完整官方通用运行库已保留，不保证所有显卡都能加速。

## 文件与数据

- `runtime/node/win32-x64/node.exe`：随包 Node.js。
- `runtime/ollama/win32-x64/`：官方 Windows Ollama 程序、依赖库与第三方许可证。
- `models/ollama/`：项目模型权重。`MODEL_FILES.json` 记录基础权重 SHA-256。
- `app/models/Modelfile`：16K 上下文的项目模型配置。
- `app/data/db/`：运行后产生的角色、设置与聊天记录，请自行备份。
- `PACKAGE_MANIFEST.json`、`SHA256SUMS`：发布文件与校验清单。

发布包保留项目原有的内置角色模板，但不打包开发机的用户聊天、角色修改、备份、API Key 或 `.env`。分享整个已运行的目录之前，需要另外检查其中新产生的个人数据。

## 故障定位

- 缺少运行程序：确认完整解压了 ZIP，两个 runtime 子目录都在，不要只复制启动脚本。
- 11435 端口被占用：先关闭另一份趣聊启动窗口，再重试。该端口专供项目模型，不复用系统的 11434 Ollama。
- 5180 端口被占用：先停止使用该端口的其他趣聊实例。
- 连接失败：保留启动窗口中的报错，并核对显卡驱动、内存和磁盘空间。
- 完整解压后的应用目录可包含中文和空格，启动脚本已为路径加引号；Windows 实机路径兼容性仍待验收。

本目录已同步 Mac 共用的调用、预算、缓存、错误提示和启动器修复。旧角色或备份中的商业模型配置不会影响新的本地调用；输入预算最高约 7000 tokens、输出最高 8192 tokens，超长完整请求会明确报错。群聊和游戏为本地冷启动保留最多 120 秒无内容等待与 5 分钟总时限，仍可随时停止。
