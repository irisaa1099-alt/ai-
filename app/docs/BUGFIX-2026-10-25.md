# 2026年10月25日 参赛稳定性与交付修订

私聊系统上下文按身份、行为与角色规则、相关记忆、可选人设分配预算，避免整体前缀截断吞掉记忆；分项总和以实际发送文本估算为准。事实按已有相关性选择，超出记忆预算的条目不冒充已发送。

手动同步顺序排空持久队列，不再采集旧全库快照覆盖磁盘。界面同步按钮调用同一路径并报告结果；导入恢复仍是明确的整库替换操作。队列无法写入的异常需导出浏览器备份后通过导入恢复，不会为了显示同步成功而丢弃操作。更新分页测试的合成夹具以显式镜像 local-only 插入的记录。

停止后重新发送时，旧生成任务只能清理自己的状态。关闭主动消息会取消在途请求，并在取数后、发请求前、落库前核对任务代际；存储事务写入前检查取消信号。手动测试入口仍可单独触发。

静态敏感路径不区分大小写，检查符号链接解析后的真实位置；Host 必须是本机服务地址与实际监听端口，跨站 Origin 和浏览器 cross-site 请求被拒绝。支持本机、实际网卡地址与既有局域网口令路径；不信任任意匹配的 Host/Origin。

命令行恢复复用 HTTP 恢复的完整校验、暂存和失败回滚，包含群消息和带类型的删除墓碑。校验失败不清理原数据。目录切换中途的进程崩溃仍不等同于数据库级跨目录事务，安全快照可用于恢复。
