一个**本地优先**的 AI 聊天网站：不是用一个聊天框，而是在养一群住在你浏览器里的角色。

给 AI 设定虚拟人设（性格、说话风格、口头禅、与你的关系、世界观），**每个人设一张角色卡、一个独立的聊天框**，形态就像社交软件里的好友列表。人设可以命名、可以随时修改，全部数据只存在你自己的电脑上。

> 除了私聊，还能**拉几个角色建个群**：群里的人看得见彼此的发言，会互相接话、吐槽、拆台；你可以插话，也可以纯粹旁观他们自己聊 —— 这就是"AI 导演"。
>
> 对应《AI对话网页项目介绍.rtf》的核心要求，并按《功能脑暴与规划.md》的路线图实现了 V1 → V1.5 → V2 的主要能力与 V3 的群聊，语音部分落地了《语音方案.md》的流式断句朗读流水线。

## 一、本地开源模型启动

```bash
cd 项目/app
node local-start.mjs
```

当前 Mac 项目已包含 Qwen3 4B 权重与 Ollama 运行程序，需要 Node.js 22+；启动后浏览器自动打开 <http://127.0.0.1:5180>，然后：

1. 点左侧 **＋** 或「从模板挑一个好友」→ 从 30+ 内置人设里选一个（傲娇青梅、温柔学姐、毒舌同事、赛博朋克黑客、心理咨询师、猫……）。
2. 点左下 **⚙ 设置 → 模型 → 测试连接**，无需商业 API Key。
3. 开始聊天。角色的回复会**流式逐字出现**，开启语音后还会**逐句念出来**。

有了两位以上好友之后，点左侧「群聊」旁边的 **＋**（或工具栏的 👥）就能建群，把他们拉进同一个房间一起聊。

> **不需要 npm install**：整个应用是原生 ES Module，零依赖、零构建步骤。
> 服务器也不需要装任何东西（只用 Node 内置模块），Node 22+ 即可。

### 启动参数

```bash
node local-start.mjs --port 8080      # 换端口
node local-start.mjs --host 0.0.0.0   # 允许局域网访问（手机同 Wi-Fi 就能用，需配访问口令，见下）
node local-start.mjs --no-open        # 不自动打开浏览器
```

### 局域网 / 手机访问（需要访问口令）

服务默认只绑定 `127.0.0.1`，只有本机能访问；**接口的信任边界就是"请求是否来自本机"**。
一旦用 `--host 0.0.0.0` 暴露到局域网，就必须在 `app/.env` 里设一个访问口令，
否则来自局域网的接口请求会被拒绝（403）：

```bash
# app/.env
AICHAT_PROXY_TOKEN=自己定一个别人猜不到的口令
```

```bash
node local-start.mjs --host 0.0.0.0
# 手机浏览器打开一次（会自动记住口令）：
#   http://<电脑局域网IP>:5180/?token=自己定一个别人猜不到的口令
```

口令保护所有本地数据与模型接口。本机访问无需口令，模型接口固定为项目本地地址，不能通过配置切换到外部供应商。

### 仅本地模型

供应商固定为本地 Ollama，所有文本调用使用项目的 Qwen3 4B。权重位于项目根目录 `models/ollama`，推理服务使用项目专属的 11435 端口。界面不提供 API Key、自定义远程地址或商业供应商。旧设置、旧角色和导入备份自动迁移到本地调用。

详见 [模型存放位置、启动与许可](docs/LOCAL-MODEL.md)。隔离边界检查：`node tools/providercheck.mjs`。

## 二、能做什么

### 角色（人设）系统
- **40 个内置人设模板**，覆盖二次元 / 日常治愈 / 职场 / 剧情冒险 / 历史名人 / 专业顾问 / 脑洞玩法七大类，一键创建再改。
  - 二次元分组里是两个《咒术回战》角色：**最强咒术师 · 五条悟**与**诅咒之王 · 两面宿傩**。两人被写成**互相讨厌的死对头**——人设的「最讨厌的人」段落、世界书条目（提到对方名字就触发）与对呛示例都按「见面必吵」写；把他们拉进同一个群聊，一句「@两面宿傩 五条悟说你不行」就能看戏。互怼有边界：不许脏话与人身攻击，也不写虐杀。
  - 剧情冒险分组里的 **魔法学院校长 · 刘元冬** 是「温和导师」型：47 岁、亚瑟兰王国灰塔学院校长、第七席大魔法师，魔法水平顶尖却从不用来压人，说话慢、爱打比方、爱拿自己的失败开玩笑（「我年轻的时候，把整座北塔烧过一遍」）。他与内置世界观预设**中世纪魔法学院**同源（同一个灰塔学院），套用那套预设即可直接开局；世界书里埋了他拒绝谈起的「北塔大火」，是关系升温的钩子。
  - 脑洞玩法分组里的 **大狗** 是「只用一个字说话」的角色：它的台词里不出现任何汉字，意思全靠「汪」的重复次数与标点区分——「汪。」=应答、「汪汪！」=高兴、「汪汪汪！」=兴奋、四声以上连成一片=情绪爆发、「汪——」=委屈、「汪……」=示弱；内容与情绪由括号里的动作和神态表达（耳朵塌下去、把下巴搁在你膝盖上）。它的世界书里附了一张**汪语对照表**，发一句 `/ooc 翻译` 就能让它用一行中文解释刚才那串汪的意思。
  - 脑洞玩法分组里的 **嘉豪 · 豪意值满格** 是「把网上的嘉豪行为全塞进人设」的角色：黑卫衣黑裤子黑口罩四件套、对着空气打碟（心里的 BGM 是《The Spectre》）、投空气篮球、暴雨天双手插兜在操场漫步、课间站上讲台用白板讲 A 股，招牌台词是「就很……你懂吧」。他有一套自我评分系统「豪意值」（打空气拳是入门，暴雨天操场漫步是中段位，完全察觉不到自己在社死叫「自在极意豪」），世界书里附了**嘉豪行为图鉴**（含起源、口头禅、游戏嘉豪图鉴）。人设里写死了边界：只调侃行为，不针对真名叫嘉豪的人；你发一句「别演了」，他会立刻放下中二腔正常说话。
- **完整角色卡**：姓名、头像（上传图片或 emoji）、性别年龄职业、一句话简介、标签、分组、主题色、初始好感度。
- **人设深度**：性格关键词、MBTI、价值观、说话风格、口头禅、常用表情、语气助词、与你的关系、如何称呼你、世界观、所处地点、禁忌话题、示例对话（few-shot）、作者备注、完整系统提示词。
- **你自己也有一张卡（设置 → 我的资料）**：昵称、头像（上传图片或 emoji）与**性别**。昵称会被角色用来称呼你；性别与昵称会一起写进提示词的「关于对方」段落（群里也会写进成员名单），让角色在称呼与用词上贴合你。选「不设定」则完全不写进提示词，角色不会知道。
- **世界书（Lorebook）**：关键词触发式设定注入 —— 只有对话里（或你这句话里）出现了关键词，那条设定才会进提示词，所以世界观可以写得很细而不炸 token。编辑器里有独立标签页，可一键套用 **11 套内置世界观预设**（赛博朋克新港、中世纪魔法学院、末日废土、修仙九州、民国上海、太空方舟、蒸汽朋克伦敦、克苏鲁雾都、未来校园、三国乱世、异世界公会）。
  - **切换世界会自动替换**：从一套预设换到另一套时，上一套带来的设定条目会被移除（避免两个世界观同时喂给模型而自相矛盾），**你自己手写的条目会保留**。
  - 编辑器里「世界类型」是一个下拉：第一项是占位提示、中间 11 项是预设、**最后一项是「✕ 清空世界设定」**（移除当前世界的条目，保留手写条目）；旁边的「自定义」按钮可以自己写世界文案（角色卡本来就有自定义世界时会自动展开并回显）。
- **版本历史**：每次保存留档，可回滚。
- **导入导出**：兼容 SillyTavern V2 角色卡（`chara_card_v2`），也能导出成 ST 能识别的格式，社区存量人设直接搬。

### 群聊（把角色拉进同一个房间，让他们互相聊）
- **建群**：从左侧「群聊」区的 ＋ 或工具栏 👥 打开建群面板，勾选好友（≥2 位，最多 24 位），
  填群名 / 群头像 emoji / 主题色 / **群主题（会作为场景设定注入提示词，例如"凌晨三点还亮着灯的居酒屋"）**。
- **角色之间真的会互相对话**：群里每个人都能看到别人说过的话，会顺着话头接、吐槽、拆台、追问，
  而不是各自回答你。角色的"人设、口头禅、记忆、模型"全部沿用他私聊时那一套，所以在群里还是同一个人。
- **谁来说，四种策略**：
  | 策略 | 行为 |
  |---|---|
  | 智能接话（默认） | 被 @ 的人先开口，其余按"话题相关度 + 发言均衡 + 和上一位发言者的关系"挑人，刚说完的人会被降权 |
  | 轮流发言 | 按成员顺序一人一句，适合圆桌讨论 |
  | 随机插话 | 随机挑人，最容易出现意外化学反应 |
  | 只应 @ | 只有被你点名的角色才回，其余人安静旁听（你自己当导演） |
- **@ 点名**：输入 `@名字`（也有「@」按钮可点选），被点名的人一定第一个回。
- **让他们自己聊**：一键进入"圆桌模式"，你不说话他们也会自己找话题往下聊。
  - **每人至少说一次**：默认开启（群资料里可关）。人比"一轮最多"多时以人数为准——4 个人的群即使设成"一轮最多 2 位"，点一次「让他们自己聊」也是 4 个人各说一句。
  - **不必每句都提你**：这是群聊不是私聊，角色默认和群友互动；只有上下文确实和你有关（你刚说过话 / 有人提到你 / 群主题里有你）时，才会自然回应你。以前那种"每轮都问 @你 怎么看"的行为已经去掉。
  - **优先找熟人**：按角色卡资料算出"谁和谁熟"（同分组 / 同世界观 / 同地点 / 共同标签 / 资料里互相写到名字），发言时会优先接熟人的话、点熟人的名；提示词里也会列出"你在群里更熟的人"。
- **每个角色自己的声音**：开启群内朗读后，群里会一位一位地说，每人用自己的音色（先在设置 → 语音里开语音）。
- **随时打断**：生成中点发送键（或 Esc）即可停下，已经说出口的半句会保留。
- **成员管理**：顶栏或成员条上「拉人」、右键 / 长按成员头像可把他移出群；群资料里能改策略、查概况。
- **禁言**：群资料 → ✏️ 编辑里有「④ 禁言」分区，可以**指定角色**单独禁言（`speaker-off` 按钮，再点一次解除），也可以**全员禁言**（谁都不说话，只有你能往群里发消息）。
  - 被禁言的角色不会出现在发言名单里，@ 也点不出来（会提示"TA 已被禁言"）；「让 TA 再说一句」同样拦下。
  - 群资料面板里被禁言的成员会压暗并标「已禁言」，输入区上方也会提示当前状态。设置跟着群一起存进 `data/db/groups/`。
- **群聊记录**：群内搜索、收藏、复制、用 TA 的声音念一遍、让 TA 再说一句、删除单条、导出 Markdown / JSON、清空、置顶、免打扰。
- **群聊也支持命令**：`/me 动作`、`/ooc 出戏指令`、`/roll 骰子`、`/again`（让最近说话的角色再说一句）、`/stop`、`/clear`、`/help`。
- **朗读**：每个角色用自己的声线；自动朗读策略与短句上限跟随「设置 → 语音」里的配置。

### 狼人杀（群聊里的小游戏，直接在聊天页里玩）
- **入口**：群资料面板右下角的 **🎭 狼人杀** 按钮。门槛按**玩家总数**算（6~13 名 = 群成员 5~12 位 + 你）：5 位成员的群就是标准 6 人局（2 狼 + 2 民 + 预言家、女巫），12 位成员是 13 人局（12 人板 + 1 民）。
- **游戏就在聊天页里进行**（不弹窗、不切页面）：
  - **法官公告**是群里的系统消息（居中灰字）：开局、天黑、天亮、死讯、放逐投票、平票 PK、胜利结算；
  - **角色发言**就是他们的群消息，你看戏和看聊天完全一样；**而且和普通聊天一样是一个字一个字长出来的**——说完之前是一个带「正在输入…」的临时气泡，落库时才变成正式消息。推给界面的只有"发言正文"（`投票：3号` 这类格式行不会先冒出来再消失）；夜间行动/投票这类私密指令一概不推，不会把半截命令画到聊天页上；
  - **输入框上方是操作条**：轮到你刀人/查验/**投票**/开枪时出现按钮（点谁就是投谁），轮到你发言/遗言时直接在**输入框里打字发送**；
  - **投票是"盲投"**：发言之后（或跳过发言）会出现投票条，每个候选人一个按钮，点谁就是投谁；**收票期间看不到任何票数**——按钮上没有角标，HUD 只写「投票中（结果投票结束后公布）」。投票是一人一票、投完即定的，中途亮票等于替还没投的人（包括你）做决定；票数只在**本轮投票结束**那一刻才公布：法官公告印明细（`放逐投票结果：3 号 林晚 3 票…`），HUD 同时变成「投票结果：…」。懒得点就点「弃票」。
    平票 PK 同样是盲投：公告只说"谁平票、各几票"（PK 必须知道对手是谁），**重投期间票数再次藏起来**，重投结果出来才公布。
    懒得打字投票的老习惯也保留：在发言里写「投票：3号」「投票：林晚」或只写「3号」，同样算数（会跳过按钮这一步）。
  - **圆桌条位置是游戏 HUD**：`🐺 第 N 天 · 阶段｜存活 X / Y 人｜投票中 / 投票结果…｜你是 N 号 · 身份`，右侧带**暂停 / 结束**。
  - **身份栏实时显示"该记着的事"**（不用自己记、也不用悬停）：狼人显示 `狼队友：1 号 林晚、2 号 阿哲`（队友一出局立刻标「已出局」，全都出局还会提示「你现在是独狼」）；预言家显示 `已验 1 狼 / 2 好`；女巫显示 `解药还在 · 毒药已用完`（6 人局写明「本局只有解药」）；白痴翻牌后显示 `已翻牌（失去投票权）`。
- **开启与关闭用面板**：那个面板只做三件事——开局确认（人数/板子/快速模式 + 模型自检）、查看你的身份与诊断信息、结束游戏。
- **身份只有本人知道**：每个角色的身份只注入它自己的提示词；**你的身份只画在 HUD/面板上，不进任何消息、也不会发给模型**。
- **夜间由角色自己用 AI 决定**：狼队商议刀谁、预言家选人查验、女巫决定救/毒；白天每人依次发言并投票（可悍跳、可踩人、可报查验）。AI 狼挑刀口时会带上**公开记录**（法官公告 + 白天所有发言），所以它是照着"谁跳了预言家、谁在带队冲狼"来刀的，而不是随便点一个座位。
- **自动推进**：点一次「开始游戏」就跑到分出胜负（屠边判定），随时可暂停/结束；结束后自动退出模式、清掉存档，并在群里公开所有身份。
- **不泄露隐藏信息**：HUD 只显示"存活几人"（不显示还剩几狼几神几民）；法官公布死讯时按规则**不公布死因**；局终才公开全部身份。**死因也不进任何 AI 的提示词**：角色出局时只知道"自己出局了"，不知道是被刀还是被毒（否则它会在**公开发言**的遗言里顺口说出"我是被毒的"，等于替女巫宣布毒药已经用掉）。死因只留在引擎里判"猎人能不能开枪"和局末复盘。
- **打完就散场，但角色记得玩过**：局内的法官公告与发言都带上来源标记，**不进普通群聊的提示词**——所以一局结束后角色不会继续"我投 3 号""我是预言家"。
  - 保留一条锚点：局终的「【法官】本局狼人杀结束：X 阵营胜利…大家散场，可以继续正常聊天了」会留在上下文里，角色因此知道"刚玩过、已经结束"。
  - 每人一条长期记忆：结算时会给每位角色写入自己的记忆（可在角色卡「记忆」里看到、也可手动删）——例如「（和群友玩过的游戏）9 月 17 日在群「夜谈会」玩了一局狼人杀：我是「狼人」，狼人阵营胜利，我活到了最后。」
  - 局终的「身份公开」那条**不进上下文**（否则角色会永久知道彼此的身份，影响以后的对局）；这些消息在聊天记录里照常保留可见，想复盘随时能翻。
- **狼人既不自曝、也不出卖队友**：狼人悍跳预言家时如果把"查杀"报到自己同伴头上，等于替好人清狼坑——所以这条也被当成红线：① 提示词里写明"绝不能指认同伴是狼、也不能说同伴可疑；假查验要泼给好人，要卖只能卖已经出局的死人"；② 万一模型犯了，引擎同样**点名纠正让它重说**；③ 还犯就把咬同伴那句**删掉**（投票行和正常发言保留），整段都违规才换场面话。实测让假模型连续"查杀队友"，群里 0 条咬同伴的发言。
- **狼人不会自曝**：狼人一旦认狼，整局博弈就没了，所以这条被当成红线处理——① 提示词里明确写"任何情况下都不要承认自己是狼人（被查杀、被票出、被逼问、遗言时都不行）"，并给出伪装手段（悍跳、倒钩、反咬、放假信息）；② 万一模型还是认了，引擎会**点名纠正让它重说一次**；③ 重说还是认，就把认狼那句**直接删掉**，整段都在认狼则换成一句不违规的场面话。所以群里永远不会出现"我是狼人"。（你自己玩的时候不受限制——你想怎么演都行。）
- **技能结果当场可见**：轮到你查验/用药时，结果会立刻以「🔒」私密提示出现在聊天区（只有你能看到，不进消息记录、也不发给任何模型）——预言家查完马上知道"3 号是狼人"，女巫用药后知道自己救了谁/毒了谁；HUD 上的身份胶囊还会显示「已验 1 狼 / 2 好」，悬停可看全部查验明细。你自己的死因同样只私下告诉你（AI 角色没有私密频道，所以它们出局时拿不到死因——见上一条）。
- **角色真的懂规则**：每个角色每轮都会收到一张**按本局板子生成的规则速查卡**（夜间用精简版、白天用完整版）——包含本局配置与场规（如"6 人局女巫只有一瓶解药"）、夜晚行动顺序、狼人每晚只能刀一个人、女巫不能自救且同一晚不能双药、猎人被毒不能开枪、白痴翻牌、平票 PK、出局者不再发言、屠边胜负；再加角色自己的私密信息（狼同伴 / 查验记录 / 药还剩几瓶）。所以角色不会瞎猜规则，也不会去做引擎不允许的事。
- **规则范围**（依据仓库根目录《狼人杀基本规则.md》）：按人数自动配板；已实现女巫（不能自救、同一晚不双药、6 人局只有解药）、猎人（被毒不能开枪）、白痴（翻牌免死一次后失去投票权）、平票 PK 重投；**未实现**警长竞选、守卫、狼王/白狼王/狼美人/隐狼/骑士等可选板子。
- **省 token**：默认「快速模式」把发言与投票合并成一次调用；一局 7 人局大致是「每晚 2~3 次 + 每天每位存活者 1 次」。
- **互不打架**：对局进行中，群聊会拒绝再开普通的「自动接话 / 让他们聊」轮次，也不会把你随手打的字混进对局（不到你说话时会提示）。

### 聊天体验（像 IM，不像工具）
- 流式输出 + 打字机效果 + "正在输入…" + 日期分割线 + 未读红点。
- 消息：**编辑、重新生成、多版本回复滑动切换（◀ 2/3 ▶）、删除、复制、收藏、引用回复**。
- 每个角色**独立的聊天记录与草稿**，切换角色不串味。
- 全文搜索：单角色内搜索 + 跨角色全局搜索，点击结果直接定位到那条消息。
- **收藏夹**：左上角工具条上的 🔖 汇总**所有收藏过的对话**（好友私聊 + 群聊合并、最新的在最上面），
  可以按关键词过滤，点一下直接跳回原消息并高亮；在收藏夹里也能取消收藏。
- 命令系统：`/me 动作`、`/ooc 出戏指令`、`/roll 骰子`、`/clear`、`/regen`、`/retry`、`/stop`、`/help`。
- 快捷短语库、Markdown 安全的纯文本气泡、深色/浅色主题、自定义强调色、移动端单栏适配。
- **顶栏 / 右栏都能收起**：顶栏工具区最右的 ^ 把整条顶栏（群聊里还包括成员条）让给消息区，只在顶部留一条细拉手；
  右栏（角色卡 / 群资料）右上角是 ✕，点它右栏收起、中栏吃掉整行，右边缘留一条竖拉手可以再拉回来。
  两个开关各自独立、可同时收起，状态记在本机（刷新后保持）。
  手机上收起顶栏后，细拉手左半边会带一个「返回列表」，不会因为顶栏藏起来就回不到列表。
- **PWA**：可以"安装"到桌面（Chrome/Edge 地址栏右侧的安装按钮），离线也能打开。

### 记忆与情感（决定"聊到第 500 条还像不像同一个人"）
- **近期经历及时互通**：同一好友刚在私聊或群聊中听到的消息，可在其他聊天中立即接上，无需等到长期摘要生成。补充最近 7 天最多 12 条跨场景原始片段，不额外调用模型；每轮占用不超过上下文预算的 20%，且最多约 1200 个估算 token。群消息记录发送时的成员，旁听者也能记住，新成员不会自动获得入群前的新消息。详情和兼容边界见 [近期经历说明](docs/RECENT-EXPERIENCES.md)。
- **滚动摘要**：历史变长时尝试把旧记录压成长期记忆。来源失效或发生人工纠正/撤回时，可能包含旧错误的摘要暂停进入模型。
- **长期记忆库**：模型可把"你的生日""你养的猫叫团子"这类信息提取成条目；每轮按简单词项相关度和更新时间选择最多 40 条有效事实，再受总预算限制。设置里可查看来源、纠正、撤回、展开历史、重新整理或清空。纠正不改聊天原文；旧记录来源缺失时会明确标记。重建全部批次成功后才保存，并拒绝覆盖等待期间的新修改。来源关联不等于事实真实，真实模型是否正确回忆仍需评测。详见 [记忆来源与纠错](docs/MEMORY-PROVENANCE.md)。
- **好感度系统**：随对话升降（0~100，陌生→认识→熟络→亲近→交心→心意相通），并**直接影响角色语气**。涨落按你这句话的情绪分档：**正面**（开心/兴奋/害羞）+2（回复够长 +3）、**中性** +1（回复够长 +2）、**负面**（生气/难过/担心）-1。
- **时间感知**：角色知道现在几点、今天是周几、你们上次聊天是几天前——久未联系时会主动念叨。
- **情绪识别**：从你的话里识别情绪（生气/难过/开心/焦虑/害羞），调整回应方式。
- **上下文预算可视化**：设置里能看清这一轮到底发了什么给模型，人设/示例/记忆/历史各占多少 token。
- **群聊小预算处理**：先预留近期经历和必要上下文，再压缩人设、示例、世界观与旧记录；无法容纳必要规则时在模型调用前停止整轮并提示预算不足。计数使用本地估算，不等于供应商实际 token 数。

### 角色主动性
- 开启后，久未联系的角色会**主动发来一条消息**（按最小间隔、免打扰时段、每日上限节流），并在侧栏显示未读红点。

### 说话（语音）
- **引擎**：浏览器内置 `speechSynthesis`（开箱即用）或云端 OpenAI 兼容 `/audio/speech`（音质更好，失败自动降级到内置）。
- **流式断句流水线**：LLM 吐字 → 断句器按标点切句（首句阈值更小，让角色快点开口）→ 逐句合成（并发 2 个、带预取与缓存）→ 串行播放。
- 每个角色**独立声线**：音色、语速、音调、自动朗读策略（不读 / 只读短回复 / 全读），可试听。
- 点任意消息的 🔊 手动朗读；朗读中气泡高亮；**随时打断**。
- **语音输入**：按住/点击麦克风说话转文字（Chrome/Edge），可设置识别完自动发送。

### 数据与隐私（本地优先 + 直接落盘）
- **角色与聊天记录直接保存在电脑上的文件里**：`app/data/db/` 下的 JSON / NDJSON 文件，关掉浏览器、重启电脑都还在。
  - `characters/<id>.json` 角色卡　`messages/<id>.ndjson` 聊天记录　`memory/<id>.json` 长期记忆
  - `settings.json` 设置（含密钥，别分享这个文件）　`runtime.json` 好感度 / 情绪 / 未读（每 0.7 秒合并写一次）　`backup-<日期>.json` 每次启动自动留的整库快照
  - 浏览器里同时保留一份 IndexedDB 做即时读写；**每次启动都会以磁盘文件为准回填**，所以哪怕浏览器数据被清理、换了浏览器，角色照样回来。
  - 想备份/换电脑：把 `app/data/db` 整个目录拷走（或整个 `项目` 文件夹）即可。
  - **好感度 / 情绪 / 未读会一起落盘**（`data/db/runtime.json`）：重启程序、换浏览器都不会退回角色卡的初始好感度。
  - **跨站防护**：本地接口 `/api/*` 只接受本机页面（Origin 校验）且写操作必须带 `Content-Type: application/json`；
    否则你只要在开着本服务时访问任意恶意网页，对方就能用一条免预检的请求把你的数据库清空。
  - **防误删保护**：如果浏览器里是空的（换了浏览器、清了数据）而电脑上还有角色，服务器会拒绝用空数据覆盖并返回 409；整库清空必须由你在「设置 → 数据」里显式确认才放行；启动快照也不会用空的覆盖当天那份"有角色"的备份。
  - **清空前自动快照**：任何整库覆盖 / 清空操作执行**之前**，服务器会先把当前全部数据另存一份 `data/db/safety-<原因>-<时间>.json`，所以误操作也能找回。
  - **从快照恢复**：
    ```bash
    node local-start.mjs --restore data/db/safety-before-wipe-2026-09-15T12-59-41.json
    ```
    恢复前还会再自动存一份当前状态（`safety-before-restore-*.json`），恢复本身也可回滚。
- 没有账号、没有云端数据库、没有埋点。用量统计只记 token 数（近 14 天汇总 + 按角色分布），不做费用估算与预算提醒。
- 设置 → 数据 里有「立即同步到文件」与「生成整库快照」。

## 六、常见问题

**Q：直接双击 index.html 打不开？**
A：ES Module 与 IndexedDB 在 `file://` 协议下受限，必须运行项目启动脚本启动本地服务器与模型（这也是麦克风、PWA 能用的前提）。

**Q：没有 API Key 能玩吗？**
A：可以。当前版本固定使用项目内的 Qwen3 模型，所有聊天功能都无需商业 API Key；权重和运行程序准备好后，文本生成可离线使用。

**Q：密钥安全吗？**
A：当前版本不需要模型密钥；只调用本机 Qwen3。旧备份可能含历史配置，分享数据前请自行检查。

**Q：角色怎么才能"记得住"我说过的事？**
A：设置 → 记忆与上下文里保持"滚动摘要"开启，长时间聊天后模型会尝试把旧对话压成记忆；也可以点"重新整理记忆"。发现记错时先查看来源，再纠正或撤回；这些操作不会改动原消息。提取和回忆效果取决于模型与上下文预算，不保证每条信息都准确保留。

**Q：语音没声音？**
A：浏览器要求"先有一次用户点击"才允许播放。在设置 → 语音里点一次「🔊 点击开启语音」即可。若是浏览器内置语音没有中文音色，请安装系统中文音色；本版本不提供云端 TTS。

**Q：数据会丢吗？**
A：不容易。角色、群聊与聊天记录除了浏览器里的副本，还会写进你电脑上的 `app/data/db/` 文件，启动时自动回填；只有当你在设置里主动"清空全部数据"时才会真的删除。

**Q：换电脑 / 换浏览器还能用吗？**
A：把整个 `项目` 文件夹（含 `app/data/db`）拷到新电脑，运行项目启动脚本，角色、群聊和聊天记录都在。

**Q：群里角色会不会互相"串味"，或者替我/替别人说话？**
A：不会。每个角色都只拿到**自己的人设**，群里的其他成员对他是"别人"，提示词里明确要求不得替他人发言；
每位角色的回复各自按他自己绑定的模型与人设生成，落库时也记着 `speakerId`，所以谁说的永远分得清。

**Q：群聊会不会很贵？**
A：一轮里有几位角色发言，就是几次模型调用（默认最多 3 位，可在群资料里改成 1~6 位），
每次只带"最近的群聊记录 + 自己的人设"，与私聊的单轮消耗相当。设置 → 群聊里能看到当前群聊总量，
想省 token 就把「一轮最多」调小、或改用「只应 @」。

**Q：群里 @ 了别人，但他没回我？**
A：检查这个群的接话策略是不是「只应 @」（右栏或顶栏可切换）；另外被点名的角色会**第一个**回，
但如果他没被点名、且这一轮名额已被其他人占满，就会排在后面或这一轮不发言。
